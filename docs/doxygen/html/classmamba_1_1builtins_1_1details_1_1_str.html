Detailed Description

A class representing a Pythonic str type. It is bidi-convertible with std::string. It is generally immutable unless if mutated through operator=() and operator+=().

In general, Mamba APIs that accept immutable string inputs should accept C++ std::string_view or std::string where possible and only use this class for return values. In-out string parameters don't make sense because this class is by definition immutable (with the exceptions noted above).

The constructors for this class provide the Pythonic str() conversion function from various builtin types, mainly other numeric value types.
