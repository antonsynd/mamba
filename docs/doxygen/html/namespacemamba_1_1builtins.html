◆ Is() [1/4]

template<typename T>
bool mamba::builtins::Is ( const T & lhs,
const T & rhs )

For value types, returns true if they compare equal. For reference types, returns true if they are the same object (via memory address), supporting the raw reference type itself via operator&() or via std::shared_ptr<T>::operator==().

This is an overloaded member function, provided for convenience. It differs from the above function only in what argument(s) it accepts.

Note
There is no second template type param because it doesn't make sense to compare the identity of objects of differing types. For polymorphic reference types, this is handled automatically because their memory addresses would be the same anyway.
